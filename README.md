# Shivakumar Portfolio

A professional portfolio website built with Flask, Python 3.14.2, HTML, CSS, and Bootstrap showcasing skills, projects, and education as a Python Full Stack Developer.

## Features

- **Responsive Design**: Fully responsive layout using Bootstrap 5.3
- **Modern UI**: Clean and professional interface with animations
- **Multiple Pages**: 
  - Home: Professional summary and overview
  - Projects: Showcase of completed projects
  - Skills: Technical skills with progress bars
  - Education: Academic background with timeline
  - Resume: Resume preview and download options
  - Contact: Contact form and social links
- **Interactive Elements**: Hover effects, form validation, smooth scrolling
- **Download Resume**: Option to download PDF resume

## Technologies Used

### Backend
- **Python 3.14.2**: Main programming language
- **Flask 3.0.0**: Web framework
- **Python-dotenv**: Environment variable management

### Frontend
- **HTML5**: Semantic markup
- **CSS3**: Custom styling with animations
- **Bootstrap 5.3**: Responsive framework
- **JavaScript**: Interactive functionality
- **Font Awesome 6.4**: Icons

### Development Tools
- **Git**: Version control
- **VS Code**: Code editor
- **GitHub**: Code repository
